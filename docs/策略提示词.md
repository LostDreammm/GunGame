## 一、火箭炮台布局

火箭炮台必须集中放置在基地邻近区域，以便一个角色能够在多个炮台之间轮流操作。

1. 基地位于地图左上区域时：

   * 炮台放置在基地右上侧或右下侧；
   * 从这些候选区域中选择3个合法且相邻的位置；
   * 优先保证3个炮台之间移动距离最短，并且同一个角色能够轮流控制。

2. 基地位于地图右下区域时：

   * 炮台放置在基地左上侧或左下侧；
   * 同样选择3个合法且相邻的位置。

3. 位置选择要求：

   * 不得超出地图边界；
   * 不得与基地、围墙、资源、其他建筑或不可通行格重叠；
   * 首选距离基地近、角色移动成本低的位置；
   * 首选区域无法放满3个炮台时，再在另一个候选区域补充；
   * 如果仍无法放满，需要安全降级，选择基地附近最近的合法位置，不能导致程序异常。

请根据项目现有坐标定义判断“上、下、左、右”，不要自行假定坐标轴方向。

## 二、围墙布局

围墙的位置根据基地所在区域动态决定。

### 基地位于左上区域

围墙建立在基地右侧，形成由右侧、上侧和下侧组成的防线：

* 右侧纵向放置6块；
* 上侧横向放置4块；
* 下侧横向放置4块；
* 上、下两侧分别与右侧防线共享一个转角；
* 坐标去重后，围墙总数必须为12块。

### 基地位于右下区域

围墙建立在基地左侧，形成镜像防线：

* 左侧纵向放置6块；
* 上侧横向放置4块；
* 下侧横向放置4块；
* 上、下两侧分别与左侧防线共享一个转角；
* 坐标去重后，围墙总数必须为12块。

### 通用要求

* 使用集合或其他去重机制保存围墙坐标；
* 最终有效围墙坐标数必须为12；
* 不得与基地、炮台、资源或不可建造区域重叠；
* 某个预定位置不可用时，应在对应防线附近寻找最近的合法替代位置；
* 已有围墙未被摧毁时，不要重复建造；
* 被摧毁的围墙应记录原位置，并优先在原位置重建。

## 三、夜间角色分工

进入夜晚后：

* 只安排“开拓者”操纵火箭炮台；
* 开拓者应在多个相邻炮台之间轮流控制；
* 两个工人在夜晚继续执行资源采集任务；
* 不要因为进入夜晚而默认召回或停止工人；
* 只有工人面临直接危险、路径不可达或游戏规则强制限制时，才允许中断采集。

## 四、围墙修复包库存

前期需要购买并储备围墙修复包：

* 目标库存为5个；
* 库存少于5个时，将缺少的数量加入购买计划；
* 库存达到5个后停止购买；
* 使用修复包后，如果库存低于5个，应在资金和购买条件允许时补齐；
* 不得在库存已满时重复购买；
* 如果资金不足，应在不影响必要生存行为的前提下逐步补齐。

## 五、建筑升级券购买优先级

正常情况下，购买优先级为：

1. 武器升级券
2. 围墙升级券
3. 基地升级券

当基地当前血量低于最大血量的50%时，优先级动态调整为：

1. 武器升级券
2. 基地升级券
3. 围墙升级券

实现要求：

* 使用 `当前血量 / 最大血量 < 0.5` 判断；
* 恰好等于50%时仍使用正常优先级；
* 每次购买前重新检查基地血量，不能只在初始化时判断；
* 高优先级物品无法购买时，应继续尝试下一优先级物品；
* 需要保留必要资源，避免购买升级券后无法执行紧急修复或关键建造。

## 六、围墙完成后的采集策略

围墙数量未达到12块时：

* 优先采集建造围墙所需的石头；
* 建造围墙所需的石头不得出售；
* 直到有效围墙数量达到12块。

围墙达到12块后：

* 正常情况下不再优先采集石头；
* 优先采集价值更高、收益更好的矿物；
* 如果有围墙被摧毁，则统计被摧毁的围墙数量；
* 根据重建这些围墙实际需要的石头数量，采集对应数量的石头；
* 石头数量满足重建需求后，恢复高价值矿物优先策略；
* 不要无上限囤积石头。

建议按照以下方式计算石头缺口：

```text
待重建围墙数 = 12 - 当前有效围墙数
所需石头数 = 待重建围墙数 × 单块围墙消耗
石头缺口 = max(0, 所需石头数 - 当前可用石头数)
```

## 七、资源变现与剩余回合判断

采集到矿物后，应及时出售并用于建筑升级、升级券或必要道具的购买。

### 石头出售限制

* 有效围墙不足12块时，不得出售建墙所需的石头；
* 存在被摧毁围墙时，必须预留足够重建围墙的石头；
* 超出建造或重建需求的石头，才允许出售。

### 当天采集与出售决策

在开始或继续采集前，估算完成以下完整流程需要的剩余回合：

```text
完整流程回合数 =
    采集完当前资源所需回合
    + 从当前位置前往出售地点所需回合
    + 执行出售操作所需回合
```

决策规则：

```text
如果剩余回合数 >= 完整流程回合数：
    采集完当前资源；
    当天前往出售；
    出售允许变现的资源；
    按优先级购买建筑升级券或必要道具。
否则：
    继续采集资源；
    不启动无法在当天完成的“采集完成后前往出售”流程；
    将出售操作延后到后续可完整执行的时机。
```

如果游戏中回合边界还需要额外的返程、安全移动或操作成本，必须将这些成本计入完整流程回合数，避免角色在途中因回合结束而无法完成出售。

## 八、统一决策顺序

每个决策周期建议按照以下顺序执行：

1. 更新基地血量、昼夜状态、剩余回合数和角色状态；
2. 检查基地及角色是否存在紧急生存风险；
3. 检查围墙是否达到12块，以及是否存在被摧毁的围墙；
4. 计算建墙或重建围墙所需的石头缺口；
5. 检查围墙修复包库存是否达到5个；
6. 根据基地血量确定升级券购买优先级；
7. 根据围墙状态选择石头或高价值矿物作为采集目标；
8. 根据剩余回合数判断当天是否能够完成“采集 + 移动 + 出售”；
9. 白天执行建造、采集、出售和购买计划；
10. 夜晚由开拓者操纵炮台，两个工人继续采集。

紧急生存行为优先于一般经济行为，但不能随意改变上述长期策略。
